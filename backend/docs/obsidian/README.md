# Obsidian vault — OpoMTSocket Go Gateway

An interlinked knowledge map of every part of the Go gateway. Open it in
[Obsidian](https://obsidian.md): **Open folder as vault → select this
`docs/obsidian` folder**.

- **Graph view** (Ctrl/Cmd+G) shows all parts and how they connect.
- **[[00 - Map of Content]]** is the hub — start there.
- **[Architecture Board.canvas](Architecture%20Board.canvas)** is a visual,
  clickable board of the runtime flow.
- Tags group notes: `#core` `#component` `#concept` `#infra` `#ops` `#api` `#security`.

Mirrors the prose docs in `../` (DOCUMENTATION.md is the full reference).
